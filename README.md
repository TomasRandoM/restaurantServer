# restaurantServer
Servidor del ecosistema de aplicaciones del restaurant. Está hecho en Spring Boot y expone diferentes endpoints que permiten el control de los datos del servidor. Además, realiza validaciones y funcionalidades automáticas diarias y semanales que permiten una mejor gestión del restaurant. Por último, fue realizado teniendo en cuenta la seguridad. Se encuentra protegido mediante JWT, por lo que se necesita autenticación para hacer uso de los endpoints.

## Tecnologías utilizadas
- Spring Boot
- Java
- JWT
- MySQL
- Lombok
- Spring Security
- Docker
- Railway
- Hibernate Envers
